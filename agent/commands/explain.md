Explain how this works. Assume I'm a senior engineer unfamiliar with this specific codebase.

Cover:
1. **What it does** — the purpose in one sentence
2. **How it works** — the key mechanism, data flow, or algorithm (not line-by-line)
3. **Key decisions** — why was it built this way? what tradeoffs were made?
4. **Entry points** — where does control flow in and out?
5. **Gotchas** — non-obvious behavior, known limitations, footguns

$@

Be concise. Skip obvious things. Focus on what's non-trivial.
