# pr-dashboard

**Skill:** `global:pr-dashboard`
**Type:** Global Command

## Purpose

Display PR dashboard for a repository showing status of all open PRs.

## Uses

- scout CLI (`scout pr-dashboard`) ← **wraps this tool**

## Used By

- User invoked for PR overview

## Workflow

1. Run scout pr-dashboard with repo owner/name
2. Display table of all open PRs:
   - PR number
   - Title
   - Author
   - Status (checks)
   - Created date
   - Labels

- [[pr-create]] - Create new PR
