# archive-week

**Skill:** `repos:notes:archive-week`
**Type:** notes Command

## Purpose

Archive the current weekly plan and create a new one.

## Uses

- File I/O (markdown files)
- Date utilities

## Used By

- User invoked weekly

## Workflow

```
1. Find current week's plan file

2. Move to archive directory
   - Rename with completion date

3. Create new week's plan file
   - Use template
   - Set dates for new week

4. Open new file for editing
```

## Related Commands

None (standalone notes utility)
