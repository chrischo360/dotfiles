# dev

**Skill:** `repos:dev`
**Type:** Repository Command

## Purpose

Show available dev commands for current repository.

## Uses

- dev CLI (`dev :docs`)
- git (repo detection)

## Used By

- User invoked for discovery

## Workflow

1. Detect current repository
2. Run `dev :docs` to show documentation
3. Display available commands for current context
